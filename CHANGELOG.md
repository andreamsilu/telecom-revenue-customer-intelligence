# Changelog

## Version 1.0.0 — 2026-07-30

- Complete Phases 1–11 of the Telecom Revenue & Customer Intelligence Platform.
- Synthetic Tanzanian telecom ecosystem with deterministic generation profiles.
- ETL dimensions, facts, and analytical marts with MoM/YoY/rolling/YTD comparisons.
- Analytics services and deterministic recommendation engine.
- Full Streamlit dashboard (9 modules) reading aggregated marts only.
- Slim dashboard marts committed for Streamlit Community Cloud demos.

### Explicitly out of scope for Version 1

- Machine learning models
- External operator APIs / real subscriber data
- AWS / Power BI
- PostgreSQL (optional future enhancement only)
